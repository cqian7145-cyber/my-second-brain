# 三、单片机是什么？

这个词非常重要。

**单片机 = Microcontroller，简称 MCU。**

MCU 全称：

> Microcontroller Unit

你可以把它理解为：

> **一台非常小、便宜、功耗低、专门控制硬件的小电脑。**

例如：

```
STM32
ESP32
Arduino Uno上的ATmega328P
RP2040
```

都属于或者围绕 MCU。

一块 MCU 内部通常已经集成：

```
CPU
+
RAM
+
Flash
+
GPIO
+
Timer
+
ADC
+
UART
+
SPI
+
I2C
+
PWM
```

所以可以直接接：

```
按钮
LED
温度传感器
编码器
舵机
电机驱动器
IMU
```

例如：

```
if (distance < 20)
{
    stop_motor();
}
```

MCU 可以实时读取距离传感器：

```
超声波传感器
      ↓
    STM32
      ↓
判断距离 < 20cm
      ↓
    PWM
      ↓
电机停止
```

这就是最典型的单片机应用。

# 四、STM32、ESP32、Arduino到底是什么关系？

这个经常混。

```
MCU
│
├── STM32
│
├── ESP32
│
├── RP2040
│
└── ATmega328P
```

**MCU 是类别。**

STM32、ESP32 是具体产品系列。

Arduino 稍微特殊：

```
Arduino
=
开发板
+
软件生态
+
编程框架
```

比如 Arduino Uno：

```
Arduino Uno开发板
        ↓
ATmega328P MCU
```

而 ESP32 开发板：

```
ESP32 DevKit
        ↓
ESP32 MCU
```

所以不要说：

> “Arduino 和单片机有什么区别？”

更准确应该是：

> Arduino 是围绕 MCU 做的一套开发生态。

# 七、嵌入式又是什么？

**单片机 ≠ 嵌入式。**

这是最容易混的地方。

嵌入式：

> Embedded System

指的是：

> **为了某一个具体设备或功能而设计的计算机系统。**

比如：

```
空调控制器
汽车ECU
无人机飞控
扫地机器人
机械臂控制器
智能摄像头
```

都属于嵌入式系统。

单片机只是嵌入式的一种实现方式。

关系是：

```
嵌入式系统
│
├── MCU嵌入式
│   ├── STM32
│   └── ESP32
│
└── Embedded Linux
    ├── Raspberry Pi
    ├── Jetson
    └── ARM Linux Board
```

所以：

```
STM32
=
偏底层嵌入式

Jetson + Ubuntu
=
嵌入式Linux
```

这两个都属于嵌入式。

# 十、RTOS 是什么？

RTOS：

> Real-Time Operating System

实时操作系统。

常见：

```
FreeRTOS
Zephyr
RT-Thread
```

例如你的 STM32 同时要：

```
Task 1：读IMU
Task 2：读编码器
Task 3：控制电机
Task 4：CAN通信
Task 5：安全检测
```

如果全写一个 while：

```
while(1)
{
    read_imu();
    read_encoder();
    motor_control();
    can_receive();
}
```

系统复杂以后就很难管理。

RTOS 可以变成：

```
CPU
│
├── Task：IMU
├── Task：Motor
├── Task：CAN
├── Task：Encoder
└── Task：Safety
```

操作系统负责调度。

这就是 RTOS。

# 十二、UART、I²C、SPI、CAN是什么？

全部属于：

> **通信协议 / 总线**

机器人里面，不同芯片需要互相讲话。

### UART

最容易理解：

```
设备A TX ─────→ RX 设备B
设备A RX ←───── TX 设备B
```

例如：

```
PC ←→ STM32
ESP32 ←→ GPS
```

优点：

> 简单。

---

### I²C

特点：

```
SDA
SCL
```

两根主要线可以连接多个设备。

例如：

```
STM32
 │
 ├── IMU
 ├── 温度传感器
 └── OLED
```

都挂在一个 I²C 总线上。

---

### SPI

通常：

```
速度更快
```

常用于：

```
高速IMU
屏幕
Flash
ADC
```

---

### CAN

这个你做机器人尤其值得学。

汽车和机器人里非常常见：

```
Motor 1
Motor 2
Motor 3
Motor 4
STM32
传感器
```

都可以挂：

```
        CAN Bus
───────────────
 │    │    │
M1   M2   M3
```

优点：

```
可靠
抗干扰
支持很多节点
```

所以：

**CAN 优先级很高。**

# 十四、PWM是什么？

PWM：

> Pulse Width Modulation

脉宽调制。

比如快速：

```
开 关 开 关 开 关
```

控制平均能量。

50%：

```
██__██__██__
```

80%：

```
████_████_████_
```

可以控制：

```
电机速度
LED亮度
舵机
```

机器人里极重要。

# 十五、ADC是什么？

ADC：

> Analog to Digital Converter

模拟转数字。

真实世界很多信号是：

```
0.13V
1.26V
2.72V
```

电脑只能处理数字。

ADC：

```
电压
↓
ADC
↓
数字
```

例如：

```
压力传感器
↓
模拟电压
↓
STM32 ADC
↓
压力数值
```

# 十六、Encoder是什么？

Encoder：

> 编码器。

用来测：

```
电机转了多少
速度多快
当前位置
```

例如：

```
Motor
 ↓
Encoder
 ↓
STM32
 ↓
实际速度 = 97 rpm
```

目标：

```
100 rpm
```

PID发现：

```
误差 = 3
```

于是增加 PWM。

形成：

```
目标速度
   ↓
PID
   ↓
PWM
   ↓
Motor
   ↓
Encoder
   └──────────→反馈
```

这叫：

**闭环控制 Closed-loop Control。**

# 十七、机器人控制里最重要的几个词

你后面控制课程会一直遇到。

### State

状态。

例如机器人：

\[ x= \begin{bmatrix} 位置\\ 速度\\ 角度\\ 角速度 \end{bmatrix} \]

就是当前机器人是什么状态。

---

### Control Input

控制输入：

\[ u \]

比如：

```
电压
电流
力矩
PWM
```

---

### Dynamics

动力学：

> 给机器人一个力，它以后怎么运动？

常见：

\[ \dot{x}=f(x,u) \]

---

### Kinematics

运动学：

> 不考虑力，只研究位置之间的关系。

机械臂：

```
关节角
↓
末端位置
```

叫：

**Forward Kinematics**

反过来：

```
想让机械臂到这个位置
↓
应该让每个关节转多少？
```

叫：

**Inverse Kinematics，IK**

# 二十三、机器人里的“坐标系”极其重要

例如机械臂可能有：

```
world
  ↓
base_link
  ↓
shoulder
  ↓
elbow
  ↓
wrist
  ↓
camera
```

一个杯子：

```
在Camera坐标系：
[0.3, 0.1, 1.2]
```

但是机械臂控制器想知道：

```
它在Base坐标系哪里？
```

需要：

\[ p_{base} = T_{base}^{camera} p_{camera} \]

这就是：

**Coordinate Transformation**

ROS2里的：

```
TF2
```

就是专门处理坐标系变换。
