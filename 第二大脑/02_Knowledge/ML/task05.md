# 02｜5–20分钟：三个核心概念

## 2.1 Shape：矩阵的形状

假设机器人进行了4次实验。

|实验编号|PWM|电压 V|RPM|
|---|---|---|---|
|1|80|7.4|42|
|2|120|7.3|100|
|3|160|7.2|165|
|4|200|7.1|230|

如果目标是根据 PWM 和电压预测 RPM，那么输入特征矩阵是：

\[ X= \begin{bmatrix} 80&7.4\\ 120&7.3\\ 160&7.2\\ 200&7.1 \end{bmatrix} \]

标签向量是：

\[ y= \begin{bmatrix} 42\\100\\165\\230 \end{bmatrix} \]

注意，我们没有把 RPM 放入输入特征矩阵，因为它正是模型需要预测的目标。

### 为什么 X.shape = (4, 2)？

观察：

```
             特征
          PWM   电压
           ↓     ↓
       ┌──────┬─────┐
样本1  │  80  │ 7.4 │
       ├──────┼─────┤
样本2  │ 120  │ 7.3 │
       ├──────┼─────┤
样本3  │ 160  │ 7.2 │
       ├──────┼─────┤
样本4  │ 200  │ 7.1 │
       └──────┴─────┘
```

4行代表4个样本。

2列代表2个特征。

因此：

```
print(X.shape)
```

输出：

```
(4, 2)
```

机器学习中通常把输入数据表示为：

\[ \boxed{X\in\mathbb{R}^{N\times D}} \]

其中：

- \(N\)：样本数量。
- \(D\)：每个样本的特征数量。

**举一反三：**

如果一个机器人采集了1000组数据，每组包含8个传感器特征：

\[ X.shape=(1000,8) \]

这意味着1000行、8列。

### Shape 与线性代数有什么联系？

你之前学习过矩阵乘法。

假设：

\[ X\in\mathbb{R}^{100\times3} \]

模型权重：

\[ w\in\mathbb{R}^{3\times1} \]

那么：

\[ Xw\in\mathbb{R}^{100\times1} \]

为什么？

因为矩阵乘法要求：

\[ (m\times n)(n\times p)=(m\times p) \]

所以：

\[ (100\times3)(3\times1)=(100\times1) \]

**直观理解：100个样本，每个样本有3个特征，经过模型计算后，每个样本得到1个预测值。**

这就是多元线性回归：

\[ \boxed{\hat y=Xw+b} \]

在这个表达式中，标量截距 \(b\) 会加到每个预测值上。

以后学习神经网络时，这个矩阵乘法会反复出现。

## 2.2 Axis：究竟沿哪个方向计算？

这是 NumPy 初学者最容易混淆的地方。

先看一个矩阵：

\[ A= \begin{bmatrix} 1&2&3\\ 4&5&6 \end{bmatrix} \]

它的形状是：

```
A.shape == (2, 3)
```

两行三列。

现在我们想计算平均值。

### 情况一：axis=0

```
A.mean(axis=0)
```

结果：

\[ \left[ \frac{1+4}{2}, \frac{2+5}{2}, \frac{3+6}{2} \right] \]

即：

\[ \boxed{[2.5,\ 3.5,\ 4.5]} \]

为什么？

因为 `axis=0` 表示**沿第0维进行归约计算**。

对于二维数组，第0维对应行数。

计算后，行这一维被消去，每列保留一个结果。

```
        第1列 第2列 第3列
          │     │     │
          ▼     ▼     ▼
        ┌───┬───┬───┐
        │ 1 │ 2 │ 3 │
        │ 4 │ 5 │ 6 │
        └───┴───┴───┘
          │     │     │
          ▼     ▼     ▼
         2.5   3.5   4.5
```

所以：

```
A.mean(axis=0).shape
```

得到：

```
(3,)
```

### 情况二：axis=1

```
A.mean(axis=1)
```

结果：

\[ \left[ \frac{1+2+3}{3}, \frac{4+5+6}{3} \right] \]

即：

\[ \boxed{[2,\ 5]} \]

为什么？

因为 `axis=1` 表示沿第1维进行归约。

对于二维数组，第1维对应列数。

计算后，列这一维被消去，每行保留一个结果。

```
        ┌───┬───┬───┐
第1行 → │ 1 │ 2 │ 3 │ → 2
        ├───┼───┼───┤
第2行 → │ 4 │ 5 │ 6 │ → 5
        └───┴───┴───┘
```

所以：

```
A.mean(axis=1).shape
```

得到：

```
(2,)
```

### 记住更本质的规律

不要死记：

`axis=0` 就是竖着算。

`axis=1` 就是横着算。

这种记忆方法到了三维张量就容易混乱。

更准确的理解是：

**axis 指定哪一个维度参与归约。默认情况下，被归约的维度会从结果的 shape 中消失。**

|原始Shape|操作|输出Shape|
|---|---|---|
|(100, 3)|mean(axis=0)|(3,)|
|(100, 3)|mean(axis=1)|(100,)|
|(100, 3)|mean(axis=None)|()|

最后一种情况表示对全部300个元素求平均，得到一个标量。

## 2.3 Broadcasting：广播机制

这是今天最重要、也最有趣的概念。

假设我们有4个电机 PWM：

```
pwm = np.array([80, 120, 160, 200])
```

现在希望每个 PWM 都增加10。

普通 Python 中，你可能使用循环：

```
result = []for value in pwm:    result.append(value + 10)
```

NumPy 可以直接：

```
result = pwm + 10
```

输出：

```
[ 90 130 170 210]
```

为什么数组能够直接加一个数字？

因为 NumPy 支持广播。

### 生活类比

假设教室里有30名学生。

老师宣布：

> 每个人的成绩统一加5分。

你不需要对30个人分别发布30条命令。

只需要一条规则，所有人都执行。

广播机制也类似：让形状兼容的数组能够进行逐元素运算。

### 从标量广播到向量广播

现在有一个矩阵：

\[ X= \begin{bmatrix} 80&7.4\\ 120&7.3\\ 160&7.2 \end{bmatrix} \]

它的形状：

\[ (3,2) \]

我们希望：

- 所有 PWM 减去100。
- 所有电压减去7。

可以写：

```
offset = np.array([100, 7])result = X - offset
```

得到：

\[ \begin{bmatrix} -20&0.4\\ 20&0.3\\ 60&0.2 \end{bmatrix} \]

这里发生了什么？

```
X.shape = (3, 2)

       PWM   电压
       ┌────┬─────┐
       │ 80 │ 7.4 │
       │120 │ 7.3 │
       │160 │ 7.2 │
       └────┴─────┘

offset.shape = (2,)

           [100, 7]

广播后，效果相当于：

       ┌─────┬───┐
       │ 100 │ 7 │
       │ 100 │ 7 │
       │ 100 │ 7 │
       └─────┴───┘
```

注意，广播通常不需要真的在内存里复制出这个大矩阵。

### 广播规则是什么？

NumPy 从**最右边的维度**开始比较。

两个维度兼容，需要满足：

1. 两个维度大小相等。
2. 或者其中一个维度大小为1。

缺少的前置维度按1处理。

例如：

```
(100, 3)
(     3)
---------
(100, 3)   可以广播
```

再看：

```
(100, 3)
(100, 1)
---------
(100, 3)   可以广播
```

但是：

```
(100, 3)
(100,  )
---------
不兼容
```

为什么？

右侧维度分别是3和100，既不相等，也没有任何一个等于1。

所以不能直接广播。

如果你希望100个样本分别加上各自的一个修正值，可以将修正值改成：

```
correction.reshape(100, 1)
```

使它变成列向量。

### 3.5 为什么 `rpm_repeats.mean(axis=1)`？

```
rpm_repeats = np.array([    [41, 42, 43],    [87, 88, 89],    [131, 132, 133],    [177, 178, 179],    [223, 224, 225],    [267, 268, 269]])

形状为：

\[ (6,3) \]

6行：6组PWM实验。

3列：每组实验重复测量3次。

我们希望得到每组实验的平均转速。

因此需要对每一行中的3个数求平均。

使用：

```
rpm_repeats.mean(axis=1)

[42, 88, 132, 178, 224, 268]

X.shape == (6, 2)

2列：PWM、电压。

feature_mean = X.mean(axis=0)
```

[155.     7.15]
```

其中：

\[ \overline{PWM}=155 \]\[ \overline{V}=7.15 \]

结果的形状：

\[ (2,) \]

也就是每个特征对应一个均值。

### 3.7 为什么 `X - feature_mean` 不报错？

这里就是 Broadcasting。

我们有：

```
X.shape# (6, 2)feature_mean.shape# (2,)
```

执行：

```
X_centered = X - feature_mean
```

NumPy 自动让两个均值分别作用到对应的特征列。

例如第一行：

\[ [80,7.4]-[155,7.15] \]

得到：

\[ [-75,0.25] \]

这种操作叫作**中心化（Centering）**。

中心化后的每列均值接近0。

注意：中心化不是把所有数据变成0，而是让数据围绕0分布。

### 3.8 为什么还要除以标准差？

我们的两个特征量级不同：

PWM 大约80～230。

电压大约6.9～7.4。

如果某些算法依赖特征距离或梯度优化，不同量级可能影响学习效果。

所以经常使用标准化：

\[ \boxed{ z_{ij}=\frac{x_{ij}-\mu_j}{\sigma_j} } \]

其中：

- \(x_{ij}\)：第 \(i\) 个样本的第 \(j\) 个特征。
- \(\mu_j\)：第 \(j\) 个特征的均值。
- \(\sigma_j\)：第 \(j\) 个特征的标准差。

标准差可以理解为数据围绕平均值波动的典型尺度。

代码：

```
X_scaled = (    X - feature_mean) / feature_std
```

这实际上连续使用了两次广播：

第一次：每列减去各自的均值。

第二次：每列除以各自的标准差。

**注意：标准化不是所有模型都必须执行的操作。** 树模型通常不依赖这种缩放，而 KNN、SVM 和很多神经网络训练过程可能明显受益。

### 3.9 为什么不能使用测试集计算均值？

这里联系 Task 004 的数据泄漏。

错误：

```
mean = X.mean(axis=0)std = X.std(axis=0)X_scaled = (X - mean) / std# 之后才划分训练集、测试集
```

因为均值和标准差包含了测试集的信息。

正确：

```
train_mean = X_train.mean(axis=0)train_std = X_train.std(axis=0)X_train_scaled = (    X_train - train_mean) / train_stdX_test_scaled = (    X_test - train_mean) / train_std
```

**测试集必须使用训练集学到的标准化参数。**

如果训练集某列的标准差为0，还需要特殊处理，避免除以0。实际 sklearn 项目中通常使用 `StandardScaler` 配合 `Pipeline`。

# 04｜35–40分钟：常见错误与举一反三

## 4.1 三个常见错误

### 错误一：把 axis 理解成计算方向

不要只记住“axis=0竖着算”。

应该理解为：

**axis=0 消去第0维，axis=1 消去第1维。**

对于二维数组的求平均操作，这分别表现为按列求均值和按行求均值。

### 错误二：混淆一维数组和列向量

```
a = np.array([1, 2, 3])
```

它的形状是：

```
(3,)
```

不是：

```
(3, 1)
```

如果需要列向量：

```
a = a.reshape(-1, 1)
```

此时：

```
(3, 1)
```

这一点在 sklearn 中尤其重要。

### 错误三：广播维度不兼容

```
A = np.ones((6, 2))b = np.ones(6)C = A + b
```

这会报错。

因为：

```
(6, 2)
(   6)
```

从右侧比较：

2和6不兼容。

如果希望给每一行分别加上一个值：

```
C = A + b.reshape(6, 1)
```

这样：

```
(6, 2)
(6, 1)
```

就可以广播了。
