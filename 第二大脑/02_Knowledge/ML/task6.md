# 01｜0–5分钟：复习与基础自检

## 1.1 回顾二维数组

假设机器人进行了100次实验，每次记录：

- PWM
- 电池电压
- 电机转速

那么数据矩阵：

\[ X\in\mathbb{R}^{100\times3} \]

对应：

```
X.shape# (100, 3)
```

这里100表示样本数量，3表示每个样本包含3个数据字段。

但如果我们的目标是**根据 PWM 和电压预测转速**，就需要进一步拆分：

\[ X\in\mathbb{R}^{100\times2} \]\[ y\in\mathbb{R}^{100} \]

其中：

\[ X= \begin{bmatrix} PWM_1&V_1\\ PWM_2&V_2\\ \vdots&\vdots\\ PWM_{100}&V_{100} \end{bmatrix} \]\[ y= \begin{bmatrix} RPM_1\\ RPM_2\\ \vdots\\ RPM_{100} \end{bmatrix} \]

这就是我们之前学习的监督学习数据结构。

### 自检问题

为什么不能把 RPM 也放进 X，让模型预测 RPM？

**答案：**

因为 RPM 本身就是目标变量。如果将真实 RPM 作为输入，模型可能直接利用答案，造成目标泄漏。

可以把 DataFrame 理解为一张带有行索引和列名的数据表。

例如：

|trial_id|pwm|voltage_v|rpm|
|---|---|---|---|
|1|80|7.4|41|
|2|120|7.3|100|
|3|160|7.2|165|

在 Pandas 中：

```
import pandas as pddf = pd.DataFrame({    "pwm": [80, 120, 160],    "voltage_v": [7.4, 7.3, 7.2],    "rpm": [41, 100, 165]})
```

现在我们可以直接：

```

```

得到 PWM 列。

而不需要记住它是第几列。

## 2.2 什么是 CSV？

CSV 是 Comma-Separated Values 的缩写。

中文叫**逗号分隔值文件**。

例如一个文件 `motor.csv`：

```
pwm,voltage_v,rpm
80,7.4,41
120,7.3,100
160,7.2,165
```

第一行是列名。

后面每一行代表一条记录。

它本质上是文本文件，不是 Excel 工作簿。

优点是格式简单、跨平台，适合存储机器人实验记录。

Python 可以这样读取：

```
df = pd.read_csv("motor.csv")
```

再使用：

```
print(df.head())
```

查看前5行。

### 为什么机器人项目经常使用 CSV？

例如你的 ESP32 每100毫秒记录一次：

```
timestamp_ms,pwm,rpm
0,120,0
100,120,65
200,120,92
300,120,101
```

后续可以把这些记录保存为 CSV，再使用 Python 分析电机启动响应。

需要注意：真实串口数据可能存在丢包、时间戳误差和异常值。今天先学习读取与分析，数据清洗安排在 Task 007。

## 2.3 loc 和 iloc 有什么区别？

假设：

```
df = pd.DataFrame({    "pwm": [80, 120, 160],    "rpm": [41, 100, 165]})
```

### iloc：按位置选择

```
df.iloc[0]
```

选择第1行。

因为 Python 的位置从0开始。

```
df.iloc[0, 1]
```

选择第1行、第2列。

结果：

```
41
```

### loc：按标签选择

```
df.loc[0, "rpm"]
```

在当前默认行索引下，同样得到：

```
41
```

但两者的本质不同。

`iloc` 根据整数位置选择。

`loc` 根据行索引标签和列名选择。

如果行索引改成：

```
101
102
103
```

那么：

```
df.iloc[0]
```

仍然选择第一行。

而：

```
df.loc[101]
```

选择索引标签为101的行。

**记住：iloc 看位置，loc 看标签。**

## 2.4 groupby：为什么需要分组统计？

这是今天最重要的知识点。

假设我们在相同 PWM 下重复测量三次：

|PWM|RPM|
|---|---|
|80|40|
|80|42|
|80|41|
|120|99|
|120|101|
|120|100|

我们想知道：

**PWM=80 时，平均转速是多少？**

数学上：

\[ \overline{RPM}_{80} =\frac{40+42+41}{3}=41 \]

同样：

\[ \overline{RPM}_{120} =\frac{99+101+100}{3}=100 \]

如果有10000条记录，难道手动计算？

Pandas 提供：

```
df.groupby("pwm")["rpm"].mean()
```

它会自动：

```
原始数据
   │
   ▼
根据PWM分组
   │
   ├── PWM=80
   │     ├── 40
   │     ├── 42
   │     └── 41
   │          ↓
   │       平均41
   │
   └── PWM=120
         ├── 99
         ├── 101
         └── 100
              ↓
           平均100
```

这就是 GroupBy 的核心：

\[ \boxed{\text{Split}\rightarrow\text{Apply}\rightarrow\text{Combine}} \]

先分组，再计算，最后组合结果。

它与 NumPy 的 `axis` 有联系，但不相同。

`axis` 是沿数组维度计算；`groupby` 是根据某一列的取值，把记录划分成不同组再计算。

## 3.4 逐段理解代码

### 第一部分：DataFrame

```
raw = pd.DataFrame({    "pwm": [...],    "rpm": [...]})
```

这里传入一个字典。

字典的键成为列名。

字典中的列表成为每一列的数据。

每个列表长度必须一致。

### 第二部分：读取CSV

```
df = pd.read_csv(raw_path)
```

这里 `df` 就是 DataFrame 对象。

你可以使用：

```
df.shapedf.columnsdf.dtypesdf.head()df.describe()
```

分别查看：

- 数据形状
- 列名
- 数据类型
- 前几行
- 数值列的描述性统计

### 第三部分：条件筛选

```
high_pwm = df.loc[df["pwm"] >= 160]
```

先计算：

```
df["pwm"] >= 160
```

得到一组布尔值：

```
False
False
False
False
False
False
True
True
True
True
True
True
```

然后 Pandas 只保留对应 `True` 的行。

这种方法叫作**布尔索引（Boolean Indexing）**。

### 第四部分：分组统计

```
summary = df.groupby("pwm").agg(
    mean_rpm=("rpm", "mean")
)
```

其中：

`groupby("pwm")` 表示根据 PWM 的数值分组。

`("rpm", "mean")` 表示对每组 RPM 求平均。

`agg()` 可以一次计算多个统计量。

例如：

```
df.groupby("pwm").agg(    avg_rpm=("rpm", "mean"),    max_rpm=("rpm", "max"),    min_rpm=("rpm", "min"))
```

### 第五部分：转换为 NumPy

```
X = df[    ["pwm", "voltage_v"]].to_numpy()
```

这里双层方括号非常重要。

```
df["pwm"]
```

通常返回一个 Series。

```
df[["pwm"]]
```

返回一个 DataFrame。

对于今天的机器学习输入：

```
X.shape# (12, 2)
```

而：

```
y = df["rpm"].to_numpy()
```

得到：

```
y.shape# (12,)
```

# 04｜35–40分钟：常见错误与迁移练习

## 4.1 常见错误

**错误一：忘记 CSV 文件的实际位置。**

```
pd.read_csv("motor.csv")
```

如果当前工作目录没有这个文件，就会报 `FileNotFoundError`。

今天使用 `Path` 创建固定的子目录，可以减少这类问题。

**错误二：混淆 Series 和 DataFrame。**

```
df["pwm"]
```

返回一维 Series。

```
df[["pwm"]]
```

返回二维 DataFrame。

转换成 NumPy 后，前者通常是 `(N,)`，后者通常是 `(N,1)`。

**错误三：把分组后的均值当作每条原始记录。**

```
df.groupby("pwm")["rpm"].mean()
```

结果只有4组平均值。

原始数据仍然有12条记录。

分组统计并不会自动修改原始 DataFrame。
