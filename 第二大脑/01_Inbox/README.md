# 01_Inbox（收件箱）

> 未整理信息的临时入口。**先丢进来，之后再处理。**

## 用法

- 任何想法、链接、截图、待读文章、碎片，随手新建一条笔记丢这里。
- **不需要命名规范**，越快越好。
- 文件名建议 `YYYY-MM-DD 一句话.md`，例如 `2026-09-12 Shopify 主题留白.md`。

## 清空规则

- 定期（每天 / 每周）清空一次：
  - 能沉淀的 → 移到 [[../02_Knowledge/README|02_Knowledge]]。
  - 属于某个项目的 → 移到 [[../04_Projects/README|04_Projects]]。
  - 是待办/任务 → 移入对应项目或你的待办工具。
  - 已无价值 → 删除。
- **目标：Inbox 永远接近空。**

## 原则

> Capture（快速收集）和 Organize（整理）要分开。收集时不思考分类，分类时不打断收集。
