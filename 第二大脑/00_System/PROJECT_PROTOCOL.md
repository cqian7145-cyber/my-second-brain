# Project Protocol（项目管理协议）

> 目标：每个项目记录「**过程 + 结果**」，而不是只有最终答案。

## 项目结构

模板见 [[../04_Projects/_project-template/00_Context|项目模板]]，标准结构：

```
00_Context.md       背景与目标
01_Problem.md       要解决的问题
02_Research.md      研究资料
03_Requirements.md  需求
04_Decisions.md     关键决策（含 Why）
05_Prompts.md       用到的 Prompt
06_Experiments.md   实验记录
07_Output.md        产出
08_Retrospective.md 复盘
```

## 流程

```
问题 → 研究 → 假设 → Prompt → AI 输出 → 实验 → 决策 → 结果 → 复盘
```

## 复盘必答

1. 结果是否达到目标？
2. 最大的问题是什么？
3. 什么经验可以提炼到 [[../02_Knowledge/README|02_Knowledge]]？
4. 下次怎么做更好？

## 归档

结束的项目移动到 [[../09_Archive/README|09_Archive]]，不要删除。

## 决策记录

过程中的关键取舍，记入 [[../06_Decisions/README|06_Decisions]]，模板见 [[../06_Decisions/_decision-template|决策模板]]。
