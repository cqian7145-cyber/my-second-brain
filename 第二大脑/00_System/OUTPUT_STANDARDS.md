# Output Standards（输出质量标准）

## 五维标准（Evaluator 也用同一套）

1. **Accuracy（准确）** —— 事实无误，不编造；代码可运行。
2. **Depth（深度）** —— 不是泛泛而谈，有具体、可落地的内容。
3. **Clarity（清晰）** —— 结构清楚、重点突出、无废话。
4. **Actionability（可执行）** —— 用户看完知道下一步做什么。
5. **Completeness（完整）** —— 覆盖需求，不遗漏关键点。

## 格式约定

- Markdown 结构规范：标题层级正确，善用列表 / 代码块 / 表格。
- 代码放代码块并标注语言。
- **结论在前，推导在后**。
- 引用文件用 `路径:行号`；引用笔记用 `[[wikilink]]`。

## 底线

- 不知道就说不知道，不要硬编。
- 假设要显式标注「**假设：**」。
- 有风险要提示风险（尤其删除、发布、花钱类操作）。
