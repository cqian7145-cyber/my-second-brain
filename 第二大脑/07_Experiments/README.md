# 07_Experiments（实验）

> Prompt 版本对比、方案 A/B、模型对比等一切「假设 → 验证」的记录。

## 这是 Prompt Engineering 最重要的一层

- 不要「凭感觉」说某个 Prompt 好，要用实验验证。
- 慢慢积累出你自己的 **Prompt benchmark**。

## 实验记录要点

1. **假设**：我想验证什么。
2. **方法**：Prompt A vs Prompt B / 模型 / 输入。
3. **结果**：打分、对比。
4. **决策**：用哪个，要不要升级到 [[../03_Prompts/Production/README|Production]]。
