# 08_Reviews（复盘）

> 周期性复盘（周 / 月 / 季 / 年），看整体，不只盯单个项目。

## 与项目复盘的区别

- **项目复盘**（`04_Projects/.../08_Retrospective`）：单个项目。
- **本目录**：一段时间内，跨项目、跨领域，看方向对不对。

## 复盘模板

复制 [[_review-template|复盘模板]]，命名 `YYYY-MM-月度复盘.md` 等。

## 建议节奏

- 每周：清空 [[../01_Inbox/README|01_Inbox]] + 快速回顾。
- 每月：看方向、看项目进展、沉淀知识。
- 每季度 / 每年：大复盘，调整系统结构。
